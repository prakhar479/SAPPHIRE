About the Model

🎯
Model Purpose
What this model does
▼

This embedding model is trained on the MIREX dataset to learn compact representations of audio tracks. It uses a deep neural network to transform high-dimensional audio features into a low-dimensional embedding space where similar tracks are closer together.

🔬
Feature Extraction
How features are extracted
▼

The model extracts features like MFCCs (Mel-frequency cepstral coefficients), chroma features, and spectral descriptors from audio, then maps them to embeddings that capture the perceptual similarity between tracks.
